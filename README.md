# Badminton Rotation App

Mobile-first React app for managing live badminton match rotation on a single court.

## Features

- Add, edit, remove, and mark players as left
- Animated male/female player avatars
- Singles and doubles court layouts
- Fair random match generation with repeat-avoidance
- Old Game and New Game serve/scoring modes
- Live scoreboard with automatic serve updates
- Session persistence through `localStorage`

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
